# IS 3020 Final Project

## Student and Project Information

- Student name: Christopher Forrester-Jack
- GitHub username: CFJ200
- Project title: Personal Expense Tracker
- Application purpose: Help college students keep track of purchases and see how much they spend.

## How to Run the Application

Open `expense_tracker.py` in PyCharm and click Run. The program uses Python 3 and does not need any extra packages.

## Major Features

- Add an expense
- View saved expenses
- Calculate total spending
- View totals by category
- Search expenses
- Delete an expense
- Save and load expenses from a CSV file

## Python Concepts Used

The program uses functions, a list of dictionaries, conditionals, loops, user input, CSV file handling, and try/except for amount and ID input.

## Data Files

`data/expenses.csv` stores the expense ID, date, category, description, and amount for each purchase.

## Testing Summary

I tested adding expenses, closing and reopening the program, viewing totals, searching, deleting an expense, and entering an invalid amount. This version works, but the date checking and output formatting are still basic.
